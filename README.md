# BudgetPilot

AI-powered personal finance assistant for transaction analysis, budgeting, spending insights, and personalized financial recommendations.

## Current Stack

- Python
- FastAPI
- Pydantic

## Planned AI/ML Components

- Machine Learning for spending-pattern analysis
- NLP for transaction categorization and natural-language financial queries
- Deep Learning for representation learning
- LLM-powered financial explanations
- Agentic AI workflow for budget analysis and recommendations
- Anomaly detection and expense forecasting

## Current Status

Backend foundation implemented with FastAPI. Transaction management and AI/ML components are under active development.
